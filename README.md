# আমার হিসাব — অফলাইন ব্যবসা ম্যানেজমেন্ট অ্যাপ

সম্পূর্ণ অফলাইন চলা ব্যবসা ম্যানেজমেন্ট অ্যাপ। ইন্টারনেট ছাড়াই সব ফিচার কাজ করে — কোনো সার্ভারে ডেটা যায় না, সব হিসাব ফোনের ভেতরেই নিরাপদে সংরক্ষিত থাকে (IndexedDB)।

## ✨ ফিচারসমূহ

- **ড্যাশবোর্ড** — আজকের মোট বিক্রয়, ক্রয়, লাভ, আয়, ব্যয়, নগদ, বাকির পরিমাণ ও স্টকের মূল্যের সারসংক্ষেপ + সাম্প্রতিক লেনদেন
- **দৈনিক আয়-ব্যয়** — যেকোনো তারিখে আয়/ব্যয় এন্ট্রি, খাত ও নোটসহ
- **পণ্য ক্রয়** — কেনার সাথে সাথে স্টক বেড়ে যায়, ক্রয়মূল্য হালনাগাদ হয়
- **পণ্য বিক্রয়** — কার্ট সিস্টেম, একাধিক পণ্য, নগদ/বাকি পরিশোধ, স্টক থেকে স্বয়ংক্রিয় বাদ
- **স্টক তথ্য** — এন্ট্রির সময় ক্রয়মূল্য, বিক্রয়মূল্য ও একক প্রতি লাভের হিসাব
- **কাস্টমার ও বাকির হিসাব** — বাকি যোগ, বাকি পরিশোধ, কাস্টমারভিত্তিক লেনদেন বিবরণী
- **হিসাব শেয়ার** — কাস্টমারের হিসাব বা আজকের সারসংক্ষেপ টেক্সট আকারে WhatsApp/SMS/Messenger-এ শেয়ার (ফোনের Share Sheet)
- **পুনরায় সংশোধন ও ডিলিট** — সব এন্ট্রি (বিক্রয়, ক্রয়, আয়-ব্যয়, পণ্য, কাস্টমার) পরে এডিট বা ডিলিট করা যায়; ডিলিটে স্টক ও বাকির হিসাব স্বয়ংক্রিয়ভাবে ঠিক হয়ে যায়
- **বিল্ট-ইন ক্যালকুলেটর কিবোর্ড** — প্রতিটি মূল্য/পরিমাণ ঘরে ট্যাপ করলে নিচে ক্যালকুলেটর খোলে (+ − × ÷ হিসাব করে "প্রয়োগ" চাপলে ফলাফল বসে যায়)
- **সার্চ** — পণ্যের নাম, কাস্টমারের নাম, মোবাইল নম্বর দিয়ে খোঁজা
- **ব্যাকআপ/রিস্টোর** — সব ডেটা JSON ফাইলে সেভ ও ফেরানো যায়

## 📲 ইনস্টল করার নিয়ম (Android/iPhone)

1. GitHub Pages বা যেকোনো HTTPS হোস্টিং-এ এই ফোল্ডারটি আপলোড করুন (নিচে দেখুন)।
2. মোবাইলের **Chrome** ব্রাউজারে ঐ লিংকটি খুলুন (একবার ইন্টারনেট লাগবে)।
3. Chrome মেনু (⋮) → **"Install app" / "অ্যাপ ইনস্টল করুন"** চাপুন। (iPhone-এ Safari → Share → **Add to Home Screen**)
4. হোম স্ক্রিনে অ্যাপ আইকন আসবে। এরপর থেকে **ইন্টারনেট ছাড়াই** অ্যাপটি চলবে — সব ডেটা ও পেজ অফলাইনে লোড হবে।

### GitHub Pages-এ হোস্ট করা (৫ মিনিট)

1. GitHub-এ একটি রিপোজিটরি তৈরি করুন এবং এই ফাইলগুলো আপলোড করুন।
2. রিপোজিটরি **Settings → Pages** → Source: `main` branch, ফোল্ডার `/ (root)` → Save।
3. প্রায় ১ মিনিট পর `https://<আপনার-ইউজারনেম>.github.io/<রিপোনাম>/` ঠিকানায় অ্যাপ চালু হবে।
4. সেই ঠিকানা মোবাইলে খুলে উপরের নিয়মে ইনস্টল করুন।

> ⚠️ `file://` (সরাসরি ফাইল ওপেন) করলে অ্যাপ চলবে, তবে "অফলাইন অ্যাপ ইনস্টল" সুবিধা পেতে HTTPS হোস্টিং লাগবে।

## 🗂 ফাইল কাঠামো

```
index.html          — অ্যাপ শেল
css/style.css       — ডিজাইন
js/util.js          — বাংলা সংখ্যা/তারিখ ফরম্যাটসহ হেল্পার
js/db.js            — IndexedDB স্টোরেজ (localStorage ফলব্যাকসহ)
js/calc.js          — বিল্ট-ইন ক্যালকুলেটর কিবোর্ড
js/app.js           — সকল স্ক্রিন ও লজিক
sw.js               — সার্ভিস ওয়ার্কার (অফলাইন ক্যাশ)
manifest.webmanifest— PWA ম্যানিফেস্ট (অ্যাপ ইনস্টলের জন্য)
icons/              — অ্যাপ আইকন
```

## 🔒 ডেটা নিরাপত্তা

- সব ডেটা ফোনের ব্রাউজার স্টোরেজে (IndexedDB) থাকে — ব্রাউজারের ক্যাশ ক্লিয়ার করলে ডেটা মুছে যেতে পারে। নিয়মিত **সেটিংস → ব্যাকআপ ডাউনলোড** করে JSON ফাইলটি সংরক্ষণ রাখুন।
- নতুন ফোনে **রিস্টোর** বাটন দিয়ে পুরো হিসাব ফিরিয়ে আনা যায়।
